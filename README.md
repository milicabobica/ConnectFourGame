# ConnectFourGame

A web-based implementation of the classic Connect Four game built with Kotlin and Compose HTML. The project features an interactive and responsive user interface, configurable game board dimensions, and core game mechanics including turn-based gameplay and win detection.

## Features
* Interactive Connect Four gameplay
* Configurable board size
* Responsive web UI using Compose HTML
* Turn-based player system
* Win and draw detection
* Clean and modular project structure

## Technologies Used
* Kotlin
* Compose HTML
* Gradle

## Running the Project
After cloning the repository, start the application through the Gradle configuration in IntelliJ IDEA.

Open the terminal inside IntelliJ and run:
```bash
./gradlew jsBrowserDevelopmentRun --continuous
```
For Windows systems, use:
```bash
gradlew.bat jsBrowserDevelopmentRun --continuous
```
